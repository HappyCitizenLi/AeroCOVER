## 与地图边界规则的关系

现有 [voxel_map.cpp](../../src/vofod_mid360/src/voxel_map.cpp:618) 的 `exploreToGround()` 对起始查询点 `z_idx<=0` 直接返回连通；[strict_baseline_core.cpp](../../src/vofod_mid360/src/strict_baseline_core.cpp:180) 对包含这类点的簇停止 floating 判定。这是已有的地图边界先验，不是本次新增的地面过滤。

下界 −0.125 m 使平地 z=0 落在边界层，能够触发这条路径；第二、第三层中央则不会仅因层号触发它。该机制与本次地面附近 FP 消失相符，但这里是已知平地高度的场景配置，不应直接宣称对起伏地形或不同地面坐标同样有效。两次异步回放不是确定性重复，单次对照不证明所有细节差异均由参数造成。
